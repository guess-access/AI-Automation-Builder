# PRIME KREATIVES — AI Automation & System Improvement Builder

**Turn business problems into smarter systems.**

A fully interactive, single-file web app that takes a client from
*"I have a problem in my business"* to
*"I understand the solution, the workflow, the tools, the timeline — and I've submitted the project."*

> **Describe → Analyze → Drag → Choose → Design → Compare → Schedule → Save → Export → Submit**

No build step. No server. No dependencies. Just open `index.html` in any modern browser.

---

## Who is this for?

- **Clients** — describe a problem in plain words and leave with a clear automation plan.
- **Prime Kreatives** — receive structured, comparable project submissions instead of vague inquiries.
- **Non-technical users** — every screen is written so a business owner can understand it.
  Technical terms always ship with a plain-English explanation.

---

## The journey (11 screens)

| # | Screen | What happens |
|---|--------|--------------|
| 1 | **Welcome** | Positioning, Start Building, View Sample Project |
| 2 | **Discover** | Pick an area (Sales, Ops, Recruitment…), describe the problem, today-vs-instead, importance |
| 3 | **Analyze** | Plain-English problem summary, current process, pain points, automation opportunities (automate / AI-assist / simplify / eliminate / keep human) |
| 4 | **Method** | The Prime Kreatives 4-stage method: Identify (1–3d) → Design (2–5d) → Build (3–10d) → Optimize (ongoing) |
| 5 | **Design** | Drag-and-drop workflow canvas: triggers, AI steps, data, comms, automation, business systems, human actions. Move, edit, duplicate, delete, reorder, assign Automated / AI-assisted / Human approval / Manual |
| 6 | **Tools** | Pick your AI / automation / data / comms stack — or one-click intelligent recommendation with plain-English reasoning |
| 7 | **Options** | Three auto-generated approaches: **A Start Simple · B Smart Automation · C Scalable System**, with side-by-side comparison and plan selection |
| 8 | **Preview** | Auto-generated future-state workflow + *Your Future System* concept mockup (clearly labeled preview, never fake-live) |
| 9 | **Plan** | Auto timeline from the chosen plan (editable milestones + dates), scheduling, notes, status |
| 10 | **Review** | Client info + full automation plan + **Submit to Prime Kreatives** |
| 11 | **Projects** | Save / update / duplicate / delete / import / export, connection settings |

Plus throughout: **smart assistant panel** (missing trigger? no human checkpoint? it tells you),
**autosave + save indicator**, **unsaved-changes warning**, and a **sample project**
(*Automate Lead Follow-Up*) that demonstrates the whole flow.

## Key features

- 🧩 **Visual workflow builder** — drag blocks from the toolbox (or click to add),
  drag nodes to arrange, auto-drawn connectors, per-step tool + mode
- 🤖 **Explainable local intelligence** — analysis, tool picks, plans and timelines are
  generated by transparent rules, labeled as such. No API keys, nothing hidden
- 👁️ **Human-in-the-loop by design** — the app never assumes full automation is best
- 📄 **Export** — print/PDF summary, PNG workflow, JSON project file, CSV
- 📥 **Import** — restore any exported JSON on any computer
- 💾 **Persistence** — projects live in localStorage; autosave every 15s
- 📧 **Email submission** — pre-filled email to `prime.kreatives@gmail.com`,
  or one-click send via your own Google Apps Script endpoint (Projects → Connection settings)
- 📱 **Responsive** — full canvas on desktop, collapsible toolbox on tablet,
  vertical flow on mobile

## Run it

**Option A — double-click.** Open `index.html`. Done.

**Option B — Netlify Drop.** Drag this folder onto <https://app.netlify.com/drop>.
Your site is live in seconds (`index.html` is already at root).

**Option C — Netlify from this repo.** New site → Import from GitHub →
select `AI-Automation-Builder` → publish directory `/`, no build command.

---

## Connect email (one-click submit)

1. Open <https://script.google.com> → New project → paste in `apps-script/Code.gs`
   (ready-made: emails the full submission + attaches the project JSON).
2. Deploy → New deployment → Web app → Execute as **Me**, access **Anyone**,
   then copy the `/exec` URL.
3. In the app: Projects → Connection settings → paste → Save connection.

Without it, Submit opens the visitor's email app with everything pre-filled.
Failed sends never destroy work — the project stays saved with a Retry button.

## Tech notes

- Vanilla HTML/CSS/JS, zero frameworks, zero network calls except Google Fonts
  and social icons (works offline after first load, minus those).
- State object: client → problem → analysis → nodes → tools → plan →
  timeline → schedule → notes → status, with created/updated timestamps.
- Never stores passwords, API keys, or secrets anywhere.
