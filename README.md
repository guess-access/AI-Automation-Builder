# Prime Kreatives — AI Automation & System Improvement Builder

Turn business problems into smarter systems. A single-file, dependency-free web app:

**Describe → Analyze → Drag → Choose → Design → Compare → Schedule → Save → Export → Submit**

Open `index.html` in any modern browser — no build step, no server required.

## What's inside

- `index.html` — the full builder app (welcome, discovery, AI analysis, 4-stage method,
  drag-and-drop workflow canvas, tool selection + recommendations, 3 plan comparison,
  auto workflow generation, system mockup, timeline + scheduling, client info,
  project summary, project manager, connection settings, JSON/CSV/PNG/PDF export,
  demo project, autosave via localStorage)
- `privacy-policy.html` / `terms-legal-policy.html` — Facebook-ready policies
- `assets/prime-kreatives-logo.png` — brand mark · `favicon.svg` / `logo.svg`

## Email integration

Submit opens a pre-filled email to `prime.kreatives@gmail.com` by default.
For one-click sending, paste a Google Apps Script web-app URL into
Projects → Connection settings (the script POSTs `{subject, body, project}`
and relays via Gmail — no credentials in frontend code).
